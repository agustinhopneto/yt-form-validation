## 📖 Sobre

Um formulário de registro completo (nome, sobrenome, e-mail, empresa e data de nascimento) construído com componentes do **shadcn/ui** e validado com **Zod** através do **React Hook Form**, com foco em performance e boa experiência de uso.

## 🎯 O que você vai aprender

- Configurar Tailwind CSS e shadcn/ui em um projeto Vite + React + TypeScript
- Usar os componentes `Input`, `Label`, `Select` e `Button` do shadcn/ui
- Gerenciar formulários com `react-hook-form` sem re-renderizações desnecessárias
- Criar schemas de validação com Zod e inferir os tipos com `z.infer`
- Integrar os dois com `@hookform/resolvers/zod` e exibir as mensagens de erro

## 🚀 Como rodar

> Pré-requisito: [Node.js](https://nodejs.org/) 18+

```bash
# 1. Clone o repositório
git clone https://github.com/agustinhopneto/yt-form-validation.git
cd yt-form-validation

# 2. Instale as dependências
npm install

# 3. Rode o projeto
npm run dev
```

Acesse **http://localhost:5173** 🎉
