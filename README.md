## 📖 About

A complete registration form (first name, last name, e-mail, company and date of birth) built with **shadcn/ui** components and validated with **Zod** through **React Hook Form**, focused on performance and a good user experience.

## 🎯 What you’ll learn

- Set up Tailwind CSS and shadcn/ui in a Vite + React + TypeScript project
- Use the shadcn/ui `Input`, `Label`, `Select` and `Button` components
- Manage forms with `react-hook-form` without unnecessary re-renders
- Write validation schemas with Zod and infer types with `z.infer`
- Connect both with `@hookform/resolvers/zod` and display error messages

## 🚀 Getting started

> Prerequisite: [Node.js](https://nodejs.org/) 18+

```bash
# 1. Clone the repository
git clone https://github.com/agustinhopneto/yt-form-validation.git
cd yt-form-validation

# 2. Install the dependencies
npm install

# 3. Run the project
npm run dev
```

Open **http://localhost:5173** 🎉
